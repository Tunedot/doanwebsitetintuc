Website tin tức

Đồ án Web – Trường Đại học Kinh doanh và Công nghệ Hà Nội. Sinh viên: Nhật.

Xây dựng bằng Laravel (PHP) và MySQL, gồm 5 bảng: users, categories, articles, comments, contacts.

  • Độc giả: xem tin, tìm kiếm, bình luận, liên hệ.
  • Biên tập viên: thêm, sửa, xóa bài viết của mình.
  • Quản trị viên: quản lý chuyên mục, người dùng, bình luận, liên hệ.

Website cần PHP và MySQL nên không chạy được trên GitHub Pages. Xem hướng dẫn chạy local trong README.
